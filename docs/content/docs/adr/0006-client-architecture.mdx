# 0006 · 客户端状态、路由与外部适配

**状态：** 已接受 · **日期：** 2026-08-22

## 背景

控制台此前把全部界面放在一个 3,700 行的 `ProductPage` 里，服务端数据一部分走 React Query、一部分直接写进 Zustand store，地图投影是文件内的一个字面量对象，语音识别是 `VoiceView` 里内联的 `webkitSpeechRecognition` 调用。

这套结构能演示，但有三个问题会在生产环境放大：

1. **服务端状态没有单一来源。** 同一份数据既可能来自 query 缓存，也可能来自 store，两者失效时机不同，界面会出现自相矛盾的瞬间。
2. **没有边界的坐标转换。** 一旦某处对 WGS-84 坐标做了 GCJ-02 偏移又写回，偏移过的坐标和没偏移的坐标在数据里完全无法区分。
3. **外部服务写死在视图里。** 换一家语音识别厂商意味着改 `VoiceView`。

## 决策

### 服务端状态只经过 React Query

所有来自 API 的数据由 React Query 拉取，`RemoteDataBridge` 把结果写进 store 供视图读取；**视图不再自己发请求写 store**。store 保留的是客户端状态（locale、选中设备、模拟器种子数据）和从 SSE 推来的实时快照。

保留 store 而不是让视图直接用 `useQuery`，是因为模拟器模式必须继续工作：store 是两种模式共同的读取面，remote 模式往里灌真实数据，simulator 模式往里灌种子数据，视图对此无感。

### 视图按领域拆分为路由模块

`components/product/views/` 下一个领域一个文件，`product-page.tsx` 只剩路由到视图的映射和登录闸门。跨视图共用的加载态、错误态、toast 包装收敛到 `view-kit.tsx`。

拆分的判据是**领域**而不是行数：`fleet-view.tsx` 里的列表、详情和指令弹窗共享同一套设备语义，拆开它们只会制造需要同步修改的三个文件。

### 会话恢复是一个独立状态

`sessionRecoveryPending` 区分"已知未登录"和"还不知道"。刷新页面时先显示恢复中的占位，而不是先闪一下登录表单 —— 操作员会把那一闪读成"我被登出了"。

### 坐标系边界

平台内部一律 WGS-84（见 CONTEXT.md）。`MapProvider` 是唯一的转换点：`project` 收 WGS-84，`unproject` 吐 WGS-84，渲染用什么基准是 provider 自己的事。

`amap-provider` 转换时**同时转换视口中心**。只转点不转中心会把大部分偏移抵消掉，留下一个几十米的残差 —— 这是最危险的一种错误，因为它看起来像 GPS 噪声而不是 bug。

没有配置地图 key 时回退到内置的测试 provider，而不是报错：地图降级好过控制台打不开。

### 指令可用性闸门

`GET /api/v1/uavs/{id}/readiness` 的结果用于**决定按钮是否可点，以及告诉操作员原因**。真正的闸门在服务端 —— 客户端的判断天然滞后于 2 秒的飞行态新鲜度预算，网络往返本身就超了。

`readiness` 查询失败时**不锁定控制**。因为一个状态接口挂掉而失去降落无人机的能力，比放行一条服务端可能拒绝的指令更糟。

### 语音识别端口

`AsrAdapter` 定义 `available()` / `start()`，实现有三个：浏览器 Web Speech、火山引擎流式、以及不可用时的空实现。默认仍是浏览器识别 —— 把默认值设成"关闭"等于悄悄删掉一个正在工作的功能。

**音频只在内存中流转**：录制分片直接写进 socket 就丢弃，不落盘、不留存、不缓冲成 blob 数组，会话结束立即 `track.stop()`。操作员的语音是调度流量，不是语料。

浏览器不直连火山引擎，而是连我们自己的网关：签名所需的凭据是服务端密钥，静态导出的包里放不下秘密。

### Tauri CSP 精确白名单

`tauri.conf.json` 中的 CSP 不含任何 localhost 来源，本地开发用 `pnpm tauri:dev` 加载 `tauri.dev.conf.json` 覆盖层。生产环境的 API 域名由各自的构建覆盖层追加。

理由是 CSP 只有在列表短到"每加一条都得有人拍板"时才值回成本。详见 `src-tauri/README-csp.md`。

## 考虑过的其他方案

**A. 视图直接用 `useQuery`，去掉 store。** 拒绝：模拟器模式会失去唯一的注入点，每个视图都要自己处理"没有后端时读什么"。

**B. 坐标在 API 层转换，客户端全程 GCJ-02。** 拒绝：这样存进数据库和发给设备的坐标就变成了偏移过的坐标，飞控拿到会飞错地方。

**C. 语音识别只支持火山引擎。** 拒绝：那样没有凭据就完全没有语音功能，而浏览器识别本来就是可用的。

**D. CSP 保留 `http://localhost:8080` 以便开发。** 拒绝：打包后的应用因此获得连接本机 8080 端口的权限，XSS 可以借此外传令牌。覆盖层的一点摩擦换掉这条权限是划算的。

## 后果

- 新增视图时必须放进 `components/product/views/`，并在 `product-page.tsx` 的映射里登记。
- 任何需要坐标的新代码都必须经过 `MapProvider`；直接 import `lib/map/coordinates.ts` 视为破坏边界。
- 高德地图目前只实现了坐标契约与投影，**瓦片渲染需要 JS SDK 与地图 key**，接入时需按 `README-csp.md` 追加 CSP 来源。
- 火山引擎 ASR 需要一个服务端网关来签名上游连接，该网关尚未实现。
